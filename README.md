مشروعنا عبارة عن مساعد ذكي للدعم الفني يساعد المستخدم في حل المشاكل التقنية بطريقة سهلة وسريعة. المستخدم يكتب مشكلته، والمساعد يفهمها ويبحث عن المعلومات المناسبة ثم يعطيه خطوات للحل.

الهدف

تسهيل حل المشاكل التقنية وتقليل الوقت والجهد على المستخدم، مع توجيهه للدعم الفني إذا احتاج.

الأدوات المستخدمة

n8n لبناء وربط الـWorkflow.
AI Agent لفهم أسئلة المستخدم وتقديم الحلول.
OpenAI للذكاء الاصطناعي والـEmbeddings.
Simple Memory لحفظ سياق المحادثة.
Simple Vector Store لتخزين والبحث في معلومات الدعم الفني.
GitHub لحفظ المشروع ومشاركته.

طريقة العمل

المستخدم يرسل المشكلة → الـAI Agent يفهمها → يبحث في المعلومات المخزنة → يستخدم الذاكرة والسياق → يعطي المستخدم الحل والخطوات المناسبة.

المشروع قابل للتطوير وإضافة مصادر وأدوات جديدة مستقبلًا
